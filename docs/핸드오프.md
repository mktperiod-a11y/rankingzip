# 핸드오프

코드에는 주석을 두지 않습니다. 구조와 규칙은 이 문서와 README에 적습니다.

## 데이터 흐름

`app/rankings/data.ts`의 `pages`가 모든 순위입니다. 아래 순서로 덮어씁니다.

1. 기본 데이터: `data.ts`, `additions.ts`, `expansion.ts`, `asian-games.ts`, `games.ts`, `anime.ts`, `music.ts`
2. `audit.ts`: 확인일, 공개 보류(`noindex`, `holdReason`)
3. `completion.ts`: `data/rankings/completion.json` 보정, 최대 10개
4. `live.ts`: 자동 갱신 데이터(`data/rankings/live/*.json`)로 항목·설명·FAQ 생성
5. `portraits.ts`: 인물 사진·구단 로고
6. `brand-images.ts`: 앱 아이콘·게임 이미지

| 파일 | 내용 |
|---|---|
| `freshness.ts` | 순위별 갱신 방식(자동·직접 확인·변동 없음). 홈 카드 라벨과 README 표가 이 값을 씁니다 |
| `presentation.ts` | 상세 화면 상단 "기준"(출처+시기)과 값 이름표 |
| `data/rankings/names-ko.json` | 영어 제목·이름의 한국어 표기 |
| `data/rankings/live-images.json` | 자동 갱신 순위의 이름 → 이미지 |
| `data/image-shapes.json` | 이미지 비율(포스터 칸 맞춤용) |

## 스크립트

| 명령 | 하는 일 |
|---|---|
| `node scripts/update-records.mjs [--dry-run] [--only kbo,ufc]` | 기록 순위 자동 갱신 |
| `node scripts/update-netflix.mjs [--dry-run]` | 넷플릭스 주간 TOP 10 |
| `node scripts/update-anime.mjs [--dry-run]` | 애니메이션 순위 |
| `node scripts/update-webhard.mjs [--dry-run]` | 웹하드 순위 |
| `node scripts/fetch-portraits.mjs` | 인물 사진(자유 이용 사진만) |
| `node scripts/fetch-brand-images.mjs` | 앱 아이콘·게임 대표 이미지 |
| `node scripts/normalize-logos.mjs` | 로고 여백 정리, 타일·KBO 로고 생성 |
| `node scripts/image-shapes.mjs` | 이미지를 바꾼 뒤 실행 |
| `node scripts/build-github-pages.mjs /rankingzip out` | 정적 사이트 빌드 |
| `node scripts/check-links.mjs out /rankingzip` | 링크 확인 |

자동 실행 일정은 `.github/workflows/`에 있습니다(`update-data.yml` 매주 수·토, `update-webhard.yml` 2일마다, `pages.yml` 6시간마다 배포).

## 규칙

- 이미지는 출처가 있는 실제 이미지만 씁니다. 없으면 이름 첫 글자로 보여줍니다.
- 인물 사진은 위키미디어 공용 자유 이용 사진만 씁니다(작가·라이선스 표기 필요). 예외는 `portraits.ts`의 `PHOTO_OVERRIDE`.
- 공개 순위는 5~10개. 예외는 `completion.ts`의 `rankingCountExceptions`.
- 화면 문구는 짧게 씁니다. "점검" 대신 "업데이트·갱신·확인"을 씁니다.
- 새 순위는 `freshness.ts`에 갱신 방식을 꼭 추가합니다(없으면 테스트 실패).
